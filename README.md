# Studio Home Care | Depilação Profissional

Landing Page moderna, responsiva (Mobile-First) e de alta conversão com estética de Clínica/Spa Urbano para atendimento de Depilação Home Care em condomínios e vizinhança.

## 🚀 Tecnologias
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (via CDN)**
- **Google Fonts (Plus Jakarta Sans)**
- **Firebase Hosting & Netlify Drop Ready**

## ✨ Funcionalidades
- **Simulador Inteligente de Combos:** Cálculo automático de tempo de sessão e investimento com suporte a múltiplos serviços.
- **Agendamento Integrado:** Google Calendar Appointments em tempo real e WhatsApp dinâmico com mensagem pré-preenchida contendo os serviços selecionados.
- **Prova Social:** Galeria de fotos do setup no apartamento com Modal Lightbox e avaliações de moradores.

## 📦 Deploy
- **Firebase Hosting:**
  ```powershell
  firebase deploy --only hosting
  ```
- **Netlify:** Basta arrastar a pasta para o Netlify Drop.
